Forgot your password?

An administrator will check who you are (in person or by phone) and give you a temporary password. You choose your own at the next sign-in.

Recovery code

If you forget your password, this code lets you set a new one yourself from the sign-in screen. It works once; creating a new code cancels the old one.

Write it down or keep it in a safe place now. It will not be shown again. Do not store it with your username.
